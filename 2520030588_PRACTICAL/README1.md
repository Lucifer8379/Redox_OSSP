Question:
Develop a C program that demonstrates how a Linux operating
system executes a command entered by a user using fork(),
exec(), wait() and displays the Process IDs of parent and
child processes.

Objective:
To understand process creation and command execution in Linux.

System Calls Used:
- fork()
- exec()
- wait()
- getpid()


Linux Commands:
uname, lscpu, lsblk, ps, top

Conclusion:
This practical demonstrates process creation, command execution,
and process management in Linux.
