Question: Develop a C program that uses the system calls open(), read(), write(), and close() to copy the contents of one file to another. Explain how control transitions between user space and kernel space during execution. Use the strace utility to trace all system calls generated by the command cat sample.txt.

Objective: To understand file handling using system calls and the transition between user space and kernel space in Linux.

System Calls Used:

open()
read()
write()
close()

Linux Command:

strace cat sample.txt

Kernel Services Involved:

File opening
Reading file contents
Writing/displaying data
Closing the file

Conclusion: This practical demonstrates file copying using Linux system calls, user-space and kernel-space transitions, and tracing system calls using strace.
